# harness-platform-complete-demo

Projeto de demonstração da plataforma Harness cobrindo os módulos CI, CD, STO e CCM.

## Módulos

- CI: build, test, scan de imagens
- CD: deploy blue-green no Kubernetes
- STO: security testing orchestration
- CCM: cloud cost management

## Stack

- Python / FastAPI
- Docker
- Kubernetes (GKE)
- Terraform
- Harness
